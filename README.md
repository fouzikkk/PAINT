# Przyjazna Łapa

Przyjazna Łapa to aplikacja internetowa wspierająca proces adopcji zwierząt ze schronisk. Strona pozwala przeglądać dostępne psy i koty, sprawdzać szczegóły ogłoszeń, składać wnioski adopcyjne oraz kontaktować się z centrum adopcyjnym.

Projekt został wykonany w Django. Aplikacja zawiera część publiczną dla odwiedzających, konto użytkownika z historią wniosków i wiadomości oraz panel administratora do zarządzania zwierzętami, schroniskami, zgłoszeniami adopcyjnymi i korespondencją.

## Najważniejsze funkcje

- katalog zwierząt z filtrami i stroną szczegółów,
- formularz wniosku adopcyjnego,
- wiadomości kontaktowe z możliwością odpowiedzi administratora,
- panel użytkownika z podglądem zgłoszeń i wiadomości,
- panel administratora do obsługi ogłoszeń, schronisk, użytkowników i wniosków,
- obsługa zdjęć, plików statycznych i bazy SQLite.

## Technologie

- Python
- Django
- SQLite
- HTML, CSS, JavaScript
- PythonAnywhere

Projekt jest przygotowany do uruchomienia lokalnie oraz na hostingu PythonAnywhere.
